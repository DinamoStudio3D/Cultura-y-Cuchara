FIRESTORE RULE PATCH — MERCHANT SELF-SERVICE
==============================================
Target: firestore.rules
Branch: feature/merchant-self-service

Purpose
-------
Allow an active merchant to update ONLY the public self-service fields of a locale assigned to their UID. Admin behavior remains unchanged. Merchant create/delete remains forbidden.

1) Add this helper next to the existing merchant helper functions:

    function canMerchantEditLocale(documentId) {
      return isAssignedVisitMerchant(documentId)
        && request.resource.data.diff(resource.data).affectedKeys().hasOnly([
          'description',
          'phone',
          'whatsapp',
          'hours',
          'merchantUpdatedAt',
          'merchantUpdatedBy'
        ])
        && request.resource.data.description is string
        && request.resource.data.description.size() <= 1200
        && request.resource.data.phone is string
        && request.resource.data.phone.size() <= 30
        && request.resource.data.whatsapp is string
        && request.resource.data.whatsapp.size() <= 30
        && request.resource.data.hours is string
        && request.resource.data.hours.size() <= 600
        && request.resource.data.merchantUpdatedAt == request.time
        && request.resource.data.merchantUpdatedBy == request.auth.uid;
    }

2) Replace ONLY the current /locales rule:

    match /locales/{documentId} {
      allow read: if true;
      allow create, update, delete: if isViveLojaAdmin();
    }

with:

    match /locales/{documentId} {
      allow read: if true;
      allow create, delete: if isViveLojaAdmin();
      allow update: if isViveLojaAdmin() || canMerchantEditLocale(documentId);
    }

Security properties
-------------------
- Merchant must be authenticated and active through the existing isAssignedVisitMerchant(documentId) check.
- documentId must exist in that merchant's placeIds.
- Only six keys may change; every other key remains immutable to the merchant.
- subscription/plan cannot be changed.
- active/status cannot be changed.
- category cannot be changed.
- featured/destacado cannot be changed.
- title/name cannot be changed.
- place ownership/assignment cannot be changed.
- create/delete remain admin-only.
- merchantUpdatedBy must equal the authenticated UID.
- merchantUpdatedAt must be the Firestore server request time.

Important deployment note
-------------------------
Do not deploy this patch by itself as a rules file. It is intentionally a surgical patch for the existing firestore.rules so no unrelated rules are lost.

# V93 — Galería visual de paradas

El campo Fotografías del editor existente muestra miniaturas, identifica la portada y ofrece usar como portada, subir, bajar y quitar. Cada acción actualiza el mismo campo de URLs; los cambios solo persisten cuando el administrador guarda la parada. No se borran archivos del proveedor de imágenes.

Se refresca al editar otra parada, reiniciar el formulario o crear un atractivo desde Cantones. Los enlaces de imágenes que no cargan muestran aviso. El contenido y atributos de la vista previa están escapados y solo se previsualizan URLs HTTPS o rutas de assets. La subida de archivos no forma parte de esta versión.

Tres pruebas de interacción de galería y las 16 pruebas de cantones aprobadas con DOM simulado. Validador estático aprobado. Revisión visual y guardado real pendientes. Publicación únicamente en Preview.

# V92 — Agregar lugares turísticos desde un cantón

Administración → Cantones → seleccionar cantón → Agregar lugar turístico.

Abre el editor existente de Paradas y negocios, reinicia una ficha anterior, asigna cantón y categoría turismo, deja la publicación en borrador y deshabilita el PIN de pasaporte. No crea programas de fidelidad ni registros automáticamente. Los cambios deben guardarse explícitamente y el administrador debe elegir Publicado para hacer visible el lugar.

La galería existente recibe una URL por línea. La primera foto es portada; las otras se consultan en la ficha del lugar. Este cambio no incorpora subida de archivos.

El listado administrativo separa lugares turísticos de negocios y otras paradas. La página pública de cada cantón permite filtrar los mismos grupos sin nuevas consultas. Los filtros mantienen las reglas previas de visibilidad.

16 pruebas específicas con DOM/Firestore simulados y validador estático aprobados. No se guardaron datos reales ni se desplegaron reglas o funciones. Publicación solo Preview; revisión visual y creación con sesión administrativa pendientes.
